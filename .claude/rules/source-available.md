# Source Available ライセンス・秘匿情報ポリシー

## ソースコード公開に関する注意事項

本リポジトリは **Source Available**（ソースアベイラブル）として公開される。
**OSS（オープンソース）ではない**ことに注意。

### ライセンス形態

| 項目 | 内容 |
|------|------|
| 許可 | ソースコード閲覧、公式バイナリの使用 |
| 禁止 | 改変、再配布、商用利用、自己ビルド、競合製品作成 |

詳細は [LICENSE](../../LICENSE) を参照。

## コード品質に関する注意事項

以下に配慮すること:

- 機密情報（APIキー、トークン、パスワード等）をコードに含めない
- 内部IPアドレス、内部ホスト名、個人情報を含めない
- テストデータに実在する個人情報やメールアドレスを使用しない
- セキュリティ上のリスクがあるコード（ハードコードされた認証情報、安全でない暗号化方式等）を避ける
- デバッグ用の一時コード（例: 固定ポート、localhost限定設定）を本番コードに残さない
- 外部トラッカーの課題番号（`#123` 形式）をコード・コメント・ドキュメント・commit message・ブランチ名に書かない。参照するなら、このリポジトリの GitHub issue / PR の番号か、内容そのもの

## 依存ライブラリのライセンス管理

- 新規ライブラリ導入時は、そのライセンスを確認する
- GPL/LGPL 系のライブラリは導入禁止（Source Available ライセンスと非互換）
- 依存ライブラリの帰属表示は [THIRD_PARTY_LICENSES.md](../../THIRD_PARTY_LICENSES.md) で管理

## 秘匿情報

運用上の秘匿情報はこのリポジトリに置かない:

- 対象例:
  - APIトークン、認証情報
  - 非公開サーバーのアドレス・設定
  - 運用ドキュメント
- ソースコードやコミットに秘匿情報を含めない
- `.claude/settings.json` の `Read` deny は補助的防御にとどまる（サブプロセス経由のファイル読み取りは防げない）
